# متطلبات العتاد (تقديرية — تحتاج قياساً على عتادك)

| البند | التقدير |
|---|---|
| المكتبة | فيلم 1080p ≈ 2–8 GB، 4K ≈ 15–60 GB. حلقة 45د ≈ 0.7–2 GB |
| كاش HLS | ≈ 2.2 GB/ساعة لسلّم 1080/720/480 كامل؛ remux ≈ حجم الأصل. الحد `MOVEXA_CACHE_MAX_GB` مع حذف LRU |
| الصور والبيانات الوصفية | ≈ 1 MB لكل عنوان |
| RAM | 4 GB حد أدنى، 8–16 GB مريح (ClamAV وحده ≈ 1.2 GB) |

| السيناريو | بثوث متزامنة تقريبية |
|---|---|
| Direct Play / Remux | 20+ (محدود بالقرص والشبكة، معالج شبه خامل) |
| Transcode CPU (libx264 veryfast، 1080p) | ≈ 1 بث لكل 2–3 أنوية حديثة |
| Intel Quick Sync (Gen 9+) | 4–8 بثوث 1080p |
| NVIDIA NVENC (مستهلك) | 3–5 (حد التعريف)، أكثر على Quadro |
| Live TV (إعادة ترميز) | كالتحويل؛ عملية واحدة لكل قناة مهما كان عدد المشاهدين |

> لم تُقَس هذه الأرقام على عتادك؛ استخدم لوحة المسؤول (حمل المعالج، المرمّز المختار) لقياسها.
